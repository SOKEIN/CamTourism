# Design a Modern Cambodia Tourism Discovery Website

Create a complete, modern, responsive tourism discovery website called **“VisitKH – Explore Cambodia”**.

The website helps local and international travelers discover tourist attractions throughout Cambodia. Users should be able to search destinations and browse them by **province, category, region, and attraction type**.

The website should feel modern, clean, welcoming, professional, and visually inspired by Cambodia’s nature, culture, temples, mountains, waterfalls, islands, beaches, and local communities.

---

# 1. LANGUAGE

The website must support:

* Khmer 🇰🇭
* English 🇬🇧

Add a language switcher:

**ខ្មែរ | EN**

Recommended fonts:

Khmer:

* Noto Sans Khmer
* Battambang

English:

* Inter

Make Khmer text readable with comfortable line height and spacing.

# 2. DESIGN STYLE

Use a clean and modern travel website style.

Visual characteristics:

* Large tourism photography
* Rounded cards
* 12–20px border radius
* Soft shadows
* Spacious layout
* Clean typography
* Minimal icons
* Smooth gradients
* Modern search interface
* Professional travel-platform appearance
* Mobile-friendly responsive design

Avoid overcrowding the interface.

The website should feel like a modern travel discovery platform while maintaining a clear Cambodian identity.

# FINAL DESIGN REQUIREMENTS

The final design should look like a real production-ready Cambodian tourism platform, not a basic student template.

Prioritize:

1. Easy destination discovery
2. Powerful search
3. Province-based navigation
4. Category filtering
5. Beautiful Cambodian travel photography
6. Interactive map
7. Khmer-first usability
8. Simple and clear navigation
9. Mobile responsiveness
10. Modern professional visual design

Use realistic sample data from Cambodian destinations.

Keep layouts clean and spacious.

Use Auto Layout throughout the Figma design.

Use reusable components and variants.

Use an 8px spacing system.

Use a consistent 12-column desktop grid.

Make the interface visually attractive but easy for Cambodian and international travelers to understand.

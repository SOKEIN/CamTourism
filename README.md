# 🇰🇭 CamTourism - Explore the Kingdom of Wonder | ទេសចរណ៍កម្ពុជា

> A modern, interactive web application showcasing Cambodia's rich cultural heritage, ancient temples, tropical islands, pristine waterfalls, ecotourism, and culinary delights across all **25 provinces** with **46+ authentic destinations**.

![CamTourism Preview](https://images.unsplash.com/photo-1549463601-da058868e20d?w=1200&h=600&fit=crop&auto=format)

## 🌟 Features

- 🏛️ **All 25 Provinces of Cambodia**: Authentic information, high-definition photography, top attractions, and regional categorizations.
- 🗺️ **Comprehensive Destination Discovery**: 46+ curated destinations with ratings, opening hours, ticket pricing, best travel seasons, and interactive maps.
- 🌐 **Full Bilingual Support**: Instant switching between Khmer (ភាសាខ្មែរ) and English.
- 🎨 **Modern Khmer-Themed UI**: Built with Tailwind CSS v4, smooth animations, glassmorphism, and responsive mobile-first design.
- 🔍 **Smart Search & Filters**: Search by name, category (Temples, Islands, Waterfalls, Mountains, Heritage, Ecotourism, Food), or province.
- 🌙 **Dark & Light Mode**: Seamless theme toggle tailored for comfortable daytime and night-time browsing.
- 🗄️ **Complete Database Schema & Seeds**: Includes ready-to-run MySQL/MariaDB schemas and seed data in `database/`.

## 🚀 Live Demo

- **GitHub Pages**: [https://sokein.github.io/CamTourism/](https://sokein.github.io/CamTourism/)

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite 8
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Database Assets**: MySQL / PostgreSQL SQL schemas & automated seed generators (`database/schema.sql`, `database/seeds.sql`)
- **Deployment**: GitHub Pages via GitHub Actions

## 📦 Getting Started

### Prerequisites

- Node.js 20+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/SOKEIN/CamTourism.git

# Navigate to project directory
cd CamTourism

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```
